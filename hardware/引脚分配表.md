# 引脚分配表

> 所有定义在 `firmware/inc/system.h`，改这里之前先改代码。

## P0 口 —— 数码管段码

| 引脚 | 功能 | 说明 |
|---|---|---|
| P0.0 ~ P0.7 | SEG a~g, dp | 输出段码，**必须接 10K 排阻上拉**（P0 内部无上拉） |

## P1 口 —— 信号灯

| 引脚 | 网络名 | 功能 |
|---|---|---|
| P1.0 | L_NS_R | 南北 红灯 |
| P1.1 | L_NS_Y | 南北 黄灯 |
| P1.2 | L_NS_G | 南北 绿灯 |
| P1.3 | L_EW_R | 东西 红灯 |
| P1.4 | L_EW_Y | 东西 黄灯 |
| P1.5 | L_EW_G | 东西 绿灯 |
| P1.6 | L_PD_NS_R | 南北人行 红灯 |
| P1.7 | L_PD_NS_G | 南北人行 绿灯 |

## P2 口 —— 位选 / 蜂鸣器

| 引脚 | 网络名 | 功能 |
|---|---|---|
| P2.0 | DIG_NS_H | 南北倒计时 十位 |
| P2.1 | DIG_NS_L | 南北倒计时 个位 |
| P2.2 | DIG_EW_H | 东西倒计时 十位 |
| P2.3 | DIG_EW_L | 东西倒计时 个位 |
| P2.7 | BEEP | 蜂鸣器（紧急模式常鸣） |

> 位选为低电平有效（共阴数码管公共端接地导通）。

## P3 口 —— 人行灯 / 按键

| 引脚 | 网络名 | 功能 |
|---|---|---|
| P3.0 | L_PD_EW_R | 东西人行 红灯 |
| P3.1 | L_PD_EW_G | 东西人行 绿灯 |
| P3.2 | KEY_EMG | 紧急放行按键 |
| P3.3 | KEY_NIGHT | 夜间黄闪按键 |
| P3.4 | KEY_CAR_NS | 南北车流检测（模拟地感线圈） |
| P3.5 | KEY_CAR_EW | 东西车流检测 |
| P3.6 | KEY_MODE | 定周期 / 感应模式切换 |
| P3.7 | — | 空闲，可扩展 |

## 引脚占用统计

| 项目 | 数量 |
|---|---|
| 信号灯 | 6 |
| 人行灯 | 4 |
| 数码管位选 | 4 |
| 数码管段选 | 8（P0 复用） |
| 按键 | 5 |
| 蜂鸣器 | 1 |
| **合计** | **28 / 32**，剩余 4 个（P3.7 + P2.4~P2.6） |

## 真实硬件改造提示

若要从仿真转实物：
- 按键 → 换成 **红外对射传感器** 或 **地感线圈**，输出接 P3.4/P3.5，软件无需改动（仍是下降沿计数）
- LED → 换成 **大功率 LED + 三极管驱动**（如 S8050），单片机 IO 灌电流不足
- 蜂鸣器 → 加 **三极管 + 续流二极管**，直接接 IO 会烧口
