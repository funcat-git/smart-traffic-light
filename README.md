## 一、这是什么

一个完整的十字路口信号灯控制器。不是"红灯亮 10 秒、绿灯亮 10 秒"的流水灯，而是包含：

| 功能 | 说明 |
|---|---|
| **六相位状态机** | 南北绿 → 南北黄 → 全红 → 东西绿 → 东西黄 → 全红，循环 |
| **车流感应自适应** | 有车时绿灯自动延长（最多 40s），连续无车时提前截止（最短 12s） |
| **双向倒计时显示** | 4 位数码管，两端同时显示各自剩余秒数 |
| **紧急放行** | 一键全红 + 蜂鸣，救护车/消防车通过 |
| **夜间黄闪** | 深夜低流量时段只闪黄灯 |
| **定周期 / 感应双模式** | 一键切换，方便对比演示两种控制策略 |

**技术要点**：全程序零 `delay()`，采用「定时器中断 + 非阻塞主循环」架构，响应实时、显示不闪。

## 四、快速开始

### 只想看仿真效果（不装 Keil）
```bash
git clone <仓库地址>
```
用 Proteus 打开 `simulation/TrafficLight.pdsprj`，点左下角 ▶ 运行。

### 想改代码
1. 装 Keil uVision4/5 + C51 编译器
2. 打开 `firmware/TrafficLight.uvproj`
3. 改 `firmware/src/` 里的 `.c` 文件
4. 按 F7 编译，生成的 HEX 在 `firmware/Objects/` 下
5. 把 HEX 拖进 Proteus 的 AT89C51 芯片里

详细步骤看 [docs/03-Keil工程与代码说明.md](docs/03-Keil工程与代码说明.md)。

### 提交前必跑的自检

```bash
bash tools/check_ai_output.sh
```

自动检查 10 项：阻塞延时、中断等待循环、引脚定义是否分散、定时器初值、
Keil 绝对路径、编译产物误提交、文件编码、换行符一致性等。
**全绿才允许 push。**

## 六、关键参数（改这里就能调）

全部在 `firmware/inc/system.h`：

| 宏 | 值 | 含义 |
|---|---|---|
| `GREEN_BASE` | 20 | 绿灯基准时长（秒） |
| `GREEN_MIN` | 12 | 绿灯最短（空放截止下限） |
| `GREEN_MAX` | 40 | 绿灯最长（延长上限） |
| `YEL_S` | 3 | 黄灯时长（依 GB 14886-2016） |
| `RED_S` | 2 | 全红清空时长 |
| `EXT_CARS` | 3 | 累计几辆车延长一次 |
| `EXT_STEP` | 5 | 每次延长几秒 |
| `GAP_S` | 4 | 连续几秒无车判定空放 |
| `EMG_S` | 8 | 紧急放行时长 |
