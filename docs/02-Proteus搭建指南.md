# Proteus 原理图搭建指南（照着做，30 分钟画完）

## 一、准备工作

1. 新建工程 `TrafficLight.pdsprj`，保存在 `sim/` 目录。
2. 放入 `code/` 下 Keil 生成的 `TrafficLight.hex`（Keil 编译后自动生成）。

## 二、画图顺序（**先画灯，再画数码管，最后画按键**）

一次画完再仿真，出问题难定位。按下面四步走，每步都单独仿真验证。

### 第 1 步：最小系统（5 分钟）

| 元件 | 参数 | 接法 |
|---|---|---|
| AT89C51 | — | 中心放置 |
| CRYSTAL | 12MHz | XTAL1(19) / XTAL2(18) |
| CAP ×2 | 30pF | 晶振两端 → GND |
| CAP-ELEC | 10uF | VCC → RST(9) |
| RES | 10K | RST(9) → GND |
| EA(31) | — | **接 VCC**（必须，否则不执行程序） |

> **第一个坑：EA 引脚不接 VCC，程序不跑。** 这是 Proteus 里 51 仿真最常见的死因。

### 第 2 步：六路信号灯（10 分钟）

每路：`MCU 引脚 → RES(220Ω) → LED 阳极，LED 阴极 → GND`

| LED | 颜色 | 串接电阻 | 接引脚 |
|---|---|---|---|
| D1 | LED-RED | 220Ω | P1.0 |
| D2 | LED-YELLOW | 220Ω | P1.1 |
| D3 | LED-GREEN | 220Ω | P1.2 |
| D4 | LED-RED | 220Ω | P1.3 |
| D5 | LED-YELLOW | 220Ω | P1.4 |
| D6 | LED-GREEN | 220Ω | P1.5 |

布局建议：把 D1~D3 竖排在左上（南北），D4~D6 竖排在右上（东西）。**摆放位置本身就要像路口**，截图给老师看时观感加分。

**验证**：随便写个 `P1=0x00;` 的测试 HEX，全亮即通。或者直接进入第 3 步，用正式程序验证。

### 第 3 步：数码管（10 分钟）

| 元件 | 数量 | 说明 |
|---|---|---|
| 7SEG-MPX2-CC | 2 | 双位共阴数码管，搜索时注意 **CC 不是 CA** |
| RESPACK-8 | 1 | 10K 排阻，公共端接 VCC，另一端接 P0.0~P0.7 |

接线：

```
P0.0 → 排阻 → ┬→ 数码管1-A ┬→ 数码管2-A
P0.1 → 排阻 → ┼→ 数码管1-B ┼→ 数码管2-B
 ...             ...          ...
P0.7 → 排阻 → ┴→ 数码管1-DP┴→ 数码管2-DP

P2.0 → 数码管1 的 DIG1（数码1 十位）
P2.1 → 数码管1 的 DIG2（数码2 个位）
P2.2 → 数码管2 的 DIG1（数码3 十位）
P2.3 → 数码管2 的 DIG2（数码4 个位）
```

**7SEG-MPX2-CC 的引脚编号**（Proteus 里鼠标悬停可见）：
- 1=A, 2=B, 3=C, 4=D, 5=E, 6=F, 7=G, 8=DP
- 9=DIG1, 10=DIG2

> **第二个坑：两只数码管的段码线必须并联**（A 接 A、B 接 B…），只有位选线分开。这就是"动态扫描"的物理基础——同一时刻只点亮一位，靠人眼视觉暂留形成四位同时显示的错觉。

### 第 4 步：按键与蜂鸣器（5 分钟）

| 元件 | 接法 |
|---|---|
| BUTTON ×4 | 一端接 P3.2/P3.3/P3.4/P3.5，另一端接 GND |
| RES ×4 | 10K 上拉到 VCC（或直接用 RESPACK-8） |
| SOUNDER | 正极接 P2.7，负极接 GND |

按键旁建议加文本标签：`紧急` `夜间` `南北车流` `东西车流`，Proteus 里用 `Text` 工具加，演示时一眼看懂。

### 第 5 步：人行灯（可选加分）

| LED | 接引脚 |
|---|---|
| 南北行人红 | P1.6 |
| 南北行人绿 | P1.7 |
| 东西行人红 | P3.0 |
| 东西行人绿 | P3.1 |

## 三、加载 HEX 与仿真

1. 双击 AT89C51 → `Program File` 选择 `TrafficLight.hex`。
2. `Clock Frequency` 填 `12MHz`（**必须与代码里的定时器计算一致**，否则倒计时快慢不对）。
3. 点左下角 ▶ 运行。

**如果发现倒计时比真实秒快/慢**，说明晶振频率填错了，改回 12MHz 即可。

## 四、常见故障速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 什么都不动 | EA 没接 VCC | EA(31) 接 VCC |
| 数码管全黑 | 用了共阳管但代码是共阴 | 换 7SEG-MPX2-CC，或把 `system.h` 里 `SEG_COMMON_CATHODE` 改 0 |
| 数码管显示乱码/缺段 | P0 没上拉 | 加 RESPACK-8 |
| 数码管很暗 | 限流电阻太大 | 段码线不加电阻（仿真可省），位选线串 100Ω |
| 数码管四位数字重影 | 没消隐 | 已处理，检查是否用了旧 HEX |
| LED 不亮 | 极性反了 | LED 阳极朝 MCU 侧 |
| 按键无反应 | 没上拉 | P3 有内部上拉，Proteus 中仍建议外加 10K |
| 程序跑飞 | 看门狗/中断未开 | 检查 `EA=1` 与 `ET0=1` |
