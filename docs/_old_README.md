# 智能交通灯控制系统

工训项目 · 选题二（难度：高）· 4 人小组
AT89C51 + Proteus + Keil C51

## 目录

```
智能交通灯/
├── code/                   Keil 工程源码
│   ├── system.h            引脚定义、参数宏
│   ├── main.c              状态机 + 自适应配时算法
│   ├── display.c           数码管动态扫描
│   ├── key.c               按键消抖、车流统计
│   └── timer.c             T0 中断时基
├── sim/                    Proteus 工程（自己新建 TrafficLight.pdsprj）
└── docs/
    ├── 01-方案设计书.md      ★ 总体方案（开题用）
    ├── 02-Proteus搭建指南.md  照做即可画完原理图
    ├── 03-Keil工程与代码说明.md
    ├── 04-答辩预案与测试用例.md
    └── README.md
```

## 快速开始

1. 按 `docs/02-Proteus搭建指南.md` 画原理图（约 30 分钟）
2. 按 `docs/03-Keil工程与代码说明.md` 建工程、编译出 HEX（约 5 分钟）
3. 在 Proteus 里双击 AT89C51，加载 `code/TrafficLight.hex`，晶振填 12MHz
4. 点运行，按演示脚本测试

## 核心功能

- 十字路口六相位状态机（南绿/南黄/全红/东绿/东黄/全红）
- 双位数码管双向倒计时
- **车辆感应自适应配时**：12~40s 动态绿灯，需求延长 + 空放截止
- 紧急车辆优先放行（全红 8s + 蜂鸣）
- 夜间黄闪模式
- 人行横道灯联动
